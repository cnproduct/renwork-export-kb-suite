# RenWork 外贸出口企业知识库构建总控技能 (Runtime V4)

本技能依据《外贸出口企业 AI 知识库标准框架 V3.0》，指导智能体从“企业中文/英文简介 + 企业官网 URL”冷启动，先建立 21 个模块的证据框架，再仅通过实际可用、合规的连接器补充事实。若官网采集或 CRM 连接器不可用，必须标记 `pending_supplement`，不得声称已经采集。

---

## 1. 核心工作流与两阶段建库

```
输入: 企业简介 + 官网 URL (+ 可选 CRM/OKKI 导出数据)
  │
  ├─ 阶段 A: 企业知识冷启动 (00–12, 15–20 模块)
  │    1. 校验公司名称、品牌、域名与主营业务一致性
  │    2. 检查官网采集连接器；可用时读取公开页面，不可用时记录缺口并请求用户提供资料
  │    3. 提取结构化知识并按 JSON Schema 生成标准知识卡
  │    4. 标注六态置信度 (已验证事实, 公开事实, AI推断, 建议策略, 待补充, 已失效)
  │    5. 生成业务速查卡、新人7天路径与三批缺口确认队列
  │
  └─ 阶段 B: 客户资产接入与激活 (13–14 模块)
       1. 导入/映射 CRM、OKKI、国际站客户主数据
       2. 建立 8 类核心实体图谱 (Account, Contact, Opportunity, Interaction, Transaction, ProductInterest, Task, RiskConsent)
       3. 执行 100 分动态客户优先级评分模型
       4. 输出 S/A/B/C/D 动态分层与 8 类动态跟进名单
```

## 3. 六种岗位专属视图装配规则

系统禁止将 21 模块打包为一份冗长文档强迫所有岗位阅读，必须动态装配：

1. **老板/管理层视图 (`management`)**：
   - 核心看板：知识库成熟度 (K0–K4)、主推市场/SKU、重大商机看板、8类强制审批红线（账期、底价、独家、重大索赔）、团队跟进漏斗与复盘周报。
2. **销售主管视图 (`sales_director`)**：
   - 核心看板：S/A 客户 24 小时跟进 SLA 监控、报价停滞与样品未转单预警、待审批队列、各业务员客户池容量监控。
3. **新人业务视图 (`junior_sales`)**：
   - 核心看板：业务速查卡、新人 7 天学习路径、行业与术语词典、主推产品选型表、询盘 10 步速检、对客标准话术、绝对红线禁令。
4. **资深业务视图 (`senior_sales`)**：
   - 核心看板：L3 深度背调工具、买家决策委员会穿透、Good/Better/Best 方案定制、10 类异议谈判让步矩阵、老客复购周期预警。
5. **市场/运营视图 (`marketing`)**：
   - 核心看板：品牌对外统一口径、经批准的公开产品事实与证据、B2B 发品标题与属性词库、SEO 主题集群、多语言 FAQ 矩阵。
6. **跟单/品质视图 (`operations_quality`)**：
   - 核心看板：大货产前样与签样档案、PI 单证核对表、QC 质检节点与 AQL 标准、P1/P2/P3 售后响应流程、防收款账号篡改核验机制。

## 4. 业务速查卡标准结构 (Cheat Sheet)

每家企业知识库生成时，必须在 `00_kb_governance/业务速查卡.md` 输出一页纸速查卡：
- **一句话定位**：[企业核心身份与 3 大可信背书]
- **3–5 个主推产品**：[型号/系列 + 适用买家 + 核心卖点 + MOQ + 交付周期]
- **核心买家画像**：[3类核心买家类型 + 关键痛点 + 推荐切入点]
- **询盘必问 5 项**：[1.目标市场 2.采购量/频率 3.定制要求 4.期望交期 5.目标价格/标准]
- **全年采购节奏**：[立项期 -> 样品确认期 -> 下单大货期 -> 出运期 -> 终端零售旺季]
- **不可突破红线 (8大禁令)**：
  1. 严禁未经授权承诺低于底价；
  2. 严禁未经书面审批给予 OA/远期账期；
  3. 严禁未经书面签样直接安排大货定制生产；
  4. 严禁在开发信/公开发布中承诺未持有的认证；
  5. 严禁未经多渠道（视频/电话）核验通过邮件变更公司收款银行账号；
  6. 严禁对未验证真实性的客户提供免费开模或大额免费寄样；
  7. 严禁未经管理层授权签署独家代理协议；
  8. 严禁对 P1 级重大售后质量事故擅自作出赔偿承诺。

## 5. 三批缺口确认队列执行协议

建库完成后，系统绝不一次性抛出上百个问题打扰企业，严格分为三批：
- **第 1 批（立即影响精准获客）**：主推 3 款产品、重点开拓国家、核心买家类型、可公开案例。
- **第 2 批（立即影响报价与推进）**：各产品标准 MOQ、阶梯价格变量、打样与开模政策、加急交期。
- **第 3 批（影响风控与规模化交付）**：付款方式红线、质保索赔边界、真实产能上限、客户名单接入。
