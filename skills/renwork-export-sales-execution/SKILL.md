# RenWork 外贸销售全流程执行引擎 (Runtime V4)

本技能依据《外贸出口企业 AI 知识库标准框架 V3.0》第 15–20 模块，为销售团队提供标准化、流程化、防犯错的销售推进与成交工具集。

---

## 1. 询盘 10 步速检与三层提问下钻法

### 1.1 询盘 10 步快速诊断清单
1. **国家与区域**：判断是否在企业可售合规市场内；
2. **买家渠道类型**：品牌商 / 进口商 / 经销商 / 零售商 / 电商卖家；
3. **需求产品品类**：匹配标准 SKU 还是需要开模定制；
4. **定制深度分级**：标准品 -> 轻定制 (Logo/包装) -> 改款 ODM -> 全开模 OEM；
5. **核心技术规格**：材质、尺寸、功能、电气/物理参数；
6. **采购量级与 MOQ**：首单试单量 vs 长期年采购量；
7. **包装与唛头要求**：零售彩盒 / 工业大包装 / 亚马逊 FBA 贴标；
8. **目标到货交期**：常规期 / 旺季加急 / 港口船期要求；
9. **贸易条款与目的港**：FOB / CIF / DDP / EXW；
10. **单一下一步动作 (CTA)**：24 小时内推进的明确事项。

> **首问原则**：首次回复仅聚焦当前最关键的 2–3 个核心问题，严禁一次抛出长问卷吓跑买家。

### 1.2 L1/L2/L3 三层提问下钻
- **L1 事实层**：您目前主推的规格、数量与目标交期是什么？
- **L2 影响层**：现有供应商在交期或质量上给您的上架造成了什么瓶颈？
- **L3 动因层**：此次采购立项的核心考核标准是什么？怎样算成功？

## 2. 阶梯报价方案与样品生命周期档案

### 2.1 Good / Better / Best 方案矩阵
- **Good (起步方案)**：仅填写企业已核验的标准规格、授权价格与交期；
- **Better (推荐方案)**：仅填写已确认可实现的升级材质、工艺或包装及其成本；
- **Best (定制方案)**：列出需要确认的结构、模具、签样、认证、质保与开发周期，不得默认承诺。

> 三档方案只是结构，不代表企业已经具备某配置、认证、免费政策或交期。所有数值和承诺必须来自已批准企业知识。

### 2.2 样品唯一档案生命周期
每个样品建立唯一编号（如 `SMP-202608-001`），必须留档：
- 材质/色号/容量/尺寸
- Logo 矢量图与印制位置图纸
- 快递单号与打样照片
- 客户签收与测试反馈记录
- **大货前书面签样表（未经客户签字或邮件确认签样，严禁投产大货）**

## 3. 十类高频异议应答库与三级强度

每条异议必须按照以下标准格式建立与应对：
`客户原话 -> 表面问题 -> 真实卡点假设 -> 回应策略 -> 中英文多版本话术 -> 可交换条件 -> 升级红线`

| 异议分类 | 核心卡点假设 | 推荐应对策略 | 可交换筹码 |
|---|---|---|---|
| **1. 价格高 (Price too high)** | 不清楚价值差异 / 拿低配对比 | 拆解配置与寿命成本，提供 Good/Better 阶梯 | 调整包装、增加订单量、延长交期 |
| **2. MOQ 高 (MOQ too high)** | 首单试销，担心库存风险 | 提供首单试单支持或联合生产拼批次 | 支付试单溢价、分批出货 |
| **3. 交期长 (Lead time too long)** | 赶季节促销或项目断货 | 核对真实排产后评估拆单或运输替代，不默认存在加急通道 | 需企业确认的加急条件 |
| **4. 缺少目标国认证** | 担心清关或合规风险 | 如实说明已有/可配合/尚未具备并升级合规负责人 | 认证费用和责任需审批 |
| **5. 要求 OA 账期/赊销** | 现金流紧张或行业惯例 | 只说明需财务/管理层审批，可讨论企业已批准的风险工具 | 任何账期均不可自动承诺 |
| **6. 索要免费样品** | 筛选供应商成本，存在骗样风险 | 查询企业批准的样品费、运费与抵扣政策；未知时待确认 | 样品数量、费用、物流责任 |
| **7. 要求独家代理/排他** | 担心同质化竞争 | 设定阶段采购 KPI 与首期提货量考核 | 约定季度提货量与期限 |
| **8. 模具费谁承担** | 担心新品开发沉没成本 | 查询企业模具归属、费用、返还与知识产权政策 | 任何返还或分期需审批 |
| **9. 质量担忧/未合作过** | 缺乏信任基础 | 只提供现有且有效的质量证据，可讨论验货方案与责任 | 质保和第三方验货需确认 |
| **10. 已有稳定供应商** | 转换成本高，无换商动力 | 聚焦第二备选供应商定位，从小批量特色品切入 | 快速响应试单、差异化新品 |

## 4. 八大强制升级红线 (Mandatory Escalation Triggers)

当业务员或 AI 面临以下 8 种情况时，必须中止自动化承诺，向主管/管理层发起强制审批：
1. **低于授权底价**：买家目标价低于系统设定的底线利润；
2. **账期/赊销要求**：任何 OA、远期 D/P 或取消定金的付款方式变动；
3. **免费开模/巨额打样**：客户要求我方全额垫付模具费或定制开发费；
4. **独家/区域排他协议**：客户要求特定国家或渠道的独家经营权；
5. **第三方验货或突发验厂**：涉及重大责任条款或特殊社会责任审计；
6. **P1 级重大售后索赔**：客户提出大额索赔、退运或扣除尾款；
7. **公司收款银行账户变更**：任何声称修改汇款路径的要求（必须多渠道人工复核）；
8. **客户索要我司未具备的强制认证**：严禁口头承诺已有该证书。

## 5. P1/P2/P3 售后分级响应与复盘闭环

- **P1 严重质量/交期事故（24小时响应）**：大批量不良、停售召回、重大延误。由管理层、品质、销售成立联合小组，对照签样档案与出货留样复盘。
- **P2 重要功能/包装问题（48小时响应）**：色差超标、包装破损、局部瑕疵。核对出厂 QC 与装箱照片，协商补发或下批抵扣。
- **P3 一般咨询/轻微瑕疵（72小时响应）**：工艺可接受公差范围内的咨询，输出标准解释话术与优化建议。
