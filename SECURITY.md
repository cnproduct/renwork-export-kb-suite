# Security Policy

## Supported version

Security fixes target the latest V4 release on `main`.

## Reporting

Please use GitHub private vulnerability reporting for this repository. Do not open a public issue containing credentials, customer data, tenant identifiers, exploit details, or Restricted knowledge.

## Data handling

This repository must never contain real API keys, CRM exports, customer contacts, quotes, orders, certificates under confidentiality, or operational logs. Keep runtime secrets in environment variables or a secret manager and tenant data outside Git.
